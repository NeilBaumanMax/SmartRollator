六、多任务时序图 (一个 1ms 控制周期内)
=====================================

  时间 ──────────────────────────────────────────────→

  t=0ms
    │ SysTick 中断 (1kHz)
    │   ├─ HAL_IncTick()
    │   └─ xPortSysTickHandler()
    │       └─ 任务切换检查
    │
  t=0~1ms
    │ ControlTask (Realtime) 解除阻塞 (vTaskDelayUntil)
    │   ├─ 读 ForceQueue 最新数据
    │   ├─ CPG_Step(F_ext, 0.001)
    │   └─ MotorCmdQueue 写入
    │   → MotorTxTask 就绪
    │
    │ MotorTxTask (Realtime1) 抢占运行
    │   ├─ 读 MotorCmdQueue
    │   └─ FDCAN1 发送 CAN 帧 (0x301)
    │   → 阻塞等待下一条
    │
    │ ForceSensorTask (AboveNormal) 就绪
    │   ├─ USART2 发送 MODBUS 查询帧 (8B)
    │   ├─ USART2 接收响应帧 (29B)
    │   └─ ForceQueue 写入
    │   → osDelay(10) 阻塞 10ms
    │
    │ Log_task (BelowNormal7) 后台运行
    │   ├─ 检查串口输入缓冲
    │   ├─ 周期日志输出 (每100ms)
    │   └─ 处理 ArUco 帧
    │
  t=1ms
    │ → 下一个 SysTick, 循环


七、端到端延迟分析
=================

  力传感器采样延迟:
    100Hz 轮询周期 = 10ms
    USART2 收发耗时 ≈ (29+8)×10bits/115200 ≈ 3.2ms
    → 传感器端延迟: ~11.6ms

  控制延迟:
    ControlTask 1kHz → 最坏情况等待 1ms
    CPG_Step 计算量: 浮点×20+次, <10μs
    → 控制计算延迟: <1ms

  电机通信延迟:
    MotorTxTask 队列等待: <1ms (ControlTask 写入后立即唤醒)
    CAN 帧发送: 4字节×2, 500kbps → <0.5ms
    → CAN 总线延迟: <1ms

  ───────────────────────────────────────────
  端到端总延迟: 约 12~14ms (传感器 → 电机执行)
  ───────────────────────────────────────────


八、数据新鲜度与安全保护全景
===========================

  ┌─────────────────────────────────────────────────────┐
  │                    保护层级                          │
  │                                                    │
  │  第1层: 输入保护                                     │
  │    ForceSensorTask → 检查响应帧长度 (29B)            │
  │                  → 空指针检查                        │
  │                                                    │
  │  第2层: 队列传输保护                                 │
  │    ForceQueue → 容量8, 溢出自动丢弃最旧               │
  │    ControlTask → mq_get_latest(), 只取最新          │
  │                                                    │
  │  第3层: 新鲜度检查 (ControlTask)                     │
  │    now - last_force.timestamp > 100ms → 清零 F_x=0  │
  │    now - last_fb.timestamp    > 100ms → 清零反馈    │
  │                                                    │
  │  第4层: 算法层保护 (CPG_Step)                        │
  │    输入限幅    F_ext ∈ [-500, 500] N                 │
  │    NaN/Inf检测 每个浮点状态全覆盖                     │
  │    步长限幅    dt ∈ [0.1ms, 100ms]                  │
  │    状态限幅    x, y ∈ [-5.0, 5.0]                   │
  │    导数限幅    dx, dy, a_c ∈ [-200, 200]            │
  │    参数正值    α, μ, M, D >= 0.0001                │
  │                                                    │
  │  第5层: 输出保护                                     │
  │    v_c ∈ [-0.5, 1.2] m/s                           │
  │    target_rpm ∈ [-400, 400] rpm                    │
  │                                                    │
